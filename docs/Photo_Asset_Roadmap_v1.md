参照元: `Kei_Life_OS_v2.md`
作成日: 2026-06-06

---

## 1. このロードマップの目的

撮影した写真を、単なる記録で終わらせずに **Instagram / Latte CH / note** のコンテンツ資産として計画的に使い切る。

写真は撮影して終わりではなく、「どのメディアで何回使えるか」を意識して管理する。

## 3. メディア別の写真活用ルール

### Instagram

| 用途 | 推奨構図 | 枚数目安 |
|------|---------|---------|
| フィード投稿 | 正方形 or 4:5縦 | 1〜3枚/投稿 |
| Stories | 9:16縦 | 1〜5枚/ストーリー |
| Reels サムネイル | 9:16縦・テキスト最小 | 1枚 |

活用方針:
- 神社・御朱印写真は**週1投稿**の軸にする
- テキスト過多にしない（Latte CHカードと差別化）
- フィルターは統一感を出す程度に留める（加工しすぎない）

### Latte CH（動画背景・挿入画像）

| 用途 | 推奨サイズ | 使い方 |
|------|---------|-------|
| 動画背景 | 1920×1080 横 | ぼかしてラテキャラを前面に |
| テキストカード背景 | 1920×1080 横 | 半透明のテキストエリアを重ねる |
| 挿入カット | 横構図 | 話題の場面で2〜3秒挿入 |

活用方針:
- 神社・自然系の写真は「心を整える」テーマのLatte CH動画と親和性が高い
- 人物不要・ロケーション特定不要の写真を優先して使う

### note

| 用途 | 推奨サイズ | 使い方 |
|------|---------|-------|
| 見出し画像 | 16:9横（1280×720推奨） | 記事の顔になる1枚 |
| 本文挿入 | 横構図 | 体験記の節ごとに1枚 |

活用方針:
- 1つの体験から**最低3枚**を確保しておくと1記事分まかなえる
- 御朱印の写真は「受け取ったばかり」「見開き」「手元」の3パターンで撮る

## 4. 撮影チェックリスト（シーン別）

### 神社・御朱印

| カテゴリ | ショット | 目的 |
|---------|---------|------|
| 入口 | 鳥居・正面（正面・斜め2パターン） | Instagram フィード |
| 参道 | 石畳・参道の奥行き | note見出し・Instagram |
| 境内 | 自然光の差し込む場所 | Latte CH背景 |
| 本殿 | 遠め・威圧感のない構図 | note・Instagram |
| 御朱印 | ①受け取り直後のクローズアップ ②見開き ③手元 | Instagram / note |
| 季節感 | 花・紅葉・苔など | Instagram |

### 自然・景色

| カテゴリ | ショット | 目的 |
|---------|---------|------|
| 滝・川 | 縦構図（Reels向け） | Instagram Reels |
| 山道 | 奥行きある構図 | note見出し・Latte CH |
| 朝靄・光 | 光の筋が見える瞬間 | Instagram・note |

### 日常・ひとり時間

| カテゴリ | ショット | 目的 |
|---------|---------|------|
| 朝食・コーヒー | 手元のみ・テーブル | X・Instagram Stories |
| 読書・本 | 本の表紙・手元 | X・note |
| ジム・筋トレ | 道具・手元（顔なし） | X |
| スタジアム | 球場全景・スコアボード・グッズ（人物なし） | X・Instagram・note |

### 撮影前の確認事項

- [ ] 他者の顔が映り込まないアングルか
- [ ] 特定の職場・会社名が映り込まないか
- [ ] 住所・生活拠点が特定できるものが映っていないか
- [ ] 著作権のある看板・モニュメントをメインに撮っていないか

## 5. 写真の保存・整理ルール

### フォルダ構成（ローカル）

```
latte_images/
├── shrines/          # 神社・御朱印
│   ├── wakayama/     # 和歌山エリア
│   └── other/        # その他
├── nature/           # 自然・景色
├── daily/            # 日常・ひとり時間
├── fighters/         # 日ハム・エスコン
└── _used/            # 使用済みアーカイブ
```

### 命名規則

```
[YYYY-MM-DD]_[場所・テーマ]_[番号].jpg
例: 2026-06-15_izutama-shrine_01.jpg
```

## 7. 写真から生まれるコンテンツの流れ

```
外出・撮影
    ↓
厳選・整理（使えるものだけ残す）
    ↓
┌────────────┬───────────────┬──────────────┐
│ Instagram  │    Latte CH   │    note      │
│ 週1投稿   │  動画背景・挿入 │  記事画像    │
└────────────┴───────────────┴──────────────┘
    ↓
X告知（写真つきツイート）
    ↓
Kei Assist実績画像として蓄積
```
