## 1. このロードマップの目的

撮影した写真を、単なる記録で終わらせずに **Instagram / Latte CH / note / X** のコンテンツ資産として計画的に使い切る。

「どこで何を撮るべきか」を事前に決めておき、外出のたびに資産が積み上がる状態を作る。

## 3. シーン別 撮影チェックリスト

### 神社・パワースポット

| ショット | 構図・コツ | 用途 |
|---------|----------|------|
| 鳥居（正面） | 正中線に合わせる。空を多く入れる | Instagram フィード |
| 鳥居（斜め・奥行き） | 奥に続く列がある場合は奥行き重視 | note 見出し |
| 参道 | 朝靄・木漏れ日があれば優先。縦構図 | Latte CH背景 |
| 境内の自然 | 苔・大木・石畳のテクスチャ | Instagram / note |
| 本殿 | 遠め（威圧感なし）・空を入れる | note 見出し |
| 御朱印①受け取り直後 | 半紙が敷かれた状態ごと | Instagram フィード |
| 御朱印②見開き | 帳を開いた状態・自然光 | Instagram / note |
| 御朱印③手元 | 帳を両手で持つ・背景は境内 | X / Instagram |
| 季節の要素 | 桜・紅葉・雪・朝靄を逃さない | Instagram |

### お城

| ショット | 構図・コツ | 用途 |
|---------|----------|------|
| 外堀・水面リフレクション | 朝一・風がない時が最適 | Instagram 最強 |
| 石垣クローズアップ | テクスチャ感を出す。斜め光 | note / Instagram |
| 天守を見上げる | 下から仰ぐと迫力が出る | note 見出し |
| 天守の全景（遠望） | 広角・入口の門と一緒に収める | Instagram フィード |
| 天守×自然 | 桜・紅葉・雪があれば最優先 | Instagram 最強 |
| 城内からの眺め | 天守から見た街・山・海 | note 挿入 |

### 新幹線車窓

**座席の予約ルール**
- 富士山・伊吹山・浜名湖 → **E席**（新大阪発・東京方向では山側）
- 琵琶湖・小田原城 → **D席**（東京発・新大阪方向では逆）

| 区間 | 被写体 | 座席 | 目安の時刻 |
|------|-------|------|----------|
| 京都〜米原 | 琵琶湖 | D席 | 米原10分前 |
| 米原〜岐阜羽島 | 伊吹山 | E席 | 米原通過直後 |
| 名古屋〜浜松 | 浜名湖 | E席 | 掛川〜浜松 |
| 静岡〜三島 | **富士山**⭐ | E席 | 新富士前後 |
| 三島〜小田原 | 箱根山系 | E席 | 三島通過後 |
| 小田原〜新横浜 | 小田原城 | D席 | 小田原駅直前 |

**富士山撮影のコツ**

```
条件: 晴れ・午前便（逆光になりにくい）が理想
方法: バースト撮影（連写モード）で30〜50枚撮り、後で厳選
距離: 新富士駅通過の前後30秒が最もクリアに見える
障害: 電柱・防音壁・ほかの新幹線との交差に注意
```

### 自然・景色（滝・森・海）

| ショット | 構図・コツ | 用途 |
|---------|----------|------|
| 滝（全景） | 縦構図・スローシャッター（水を柔らかく） | Instagram Reels / note |
| 森の中の道 | 奥行き重視。光の筋があれば最優先 | Latte CH背景 |
| 海・湖（水平線） | 朝・夕の光が最強 | Instagram / note |
| 山・稜線 | 朝靄・雲海があれば即撮影 | Latte CH / note |

### 日常・ルーティン

| ショット | コツ | 用途 |
|---------|------|------|
| 朝のコーヒー・食事 | 手元のみ。テーブルの質感を活かす | X / Instagram Stories |
| 読書・本 | 表紙が見える。自然光必須 | X |
| ジム・道具 | 道具・器具のみ（顔なし） | X |

### スタジアム（エスコン等）

| ショット | コツ | 用途 |
|---------|------|------|
| 球場全景・外観 | 試合前・人が少ない時間帯 | Instagram / note |
| スコアボード | デザインとして撮る。試合情報よりも形 | Instagram |
| スタンド・座席 | 人物なしの雰囲気ショット | note 挿入 |
| フード・グッズ | テーブル・手元のみ | X / Instagram Stories |
| 夜景・照明 | 試合開始直後の雰囲気 | Instagram Reels |

## 4. 撮影前の確認（全シーン共通）

- [ ] 他者の顔が映り込まないアングルか
- [ ] 職場・会社が特定できるものが映っていないか
- [ ] 住所・生活拠点が特定できる風景でないか
- [ ] 撮影禁止エリア・本殿内部ではないか
- [ ] 著作権のある展示物をメインに撮っていないか

## 5. 写真の保存・整理ルール

### フォルダ構成（ローカル）

```
latte_images/
├── shrines/              # 神社・御朱印
│   ├── kansai/           # 関西・紀伊半島
│   ├── kanto/            # 関東
│   ├── kyoto/            # 京都
│   └── other/            # その他全国
├── castles/              # お城
├── nature/               # 自然・景色
├── shinkansen/           # 新幹線車窓
├── fighters/             # 日ハム・エスコン
├── daily/                # 日常・ルーティン
└── _used/                # 使用済みアーカイブ
```

### 命名規則

```
[YYYY-MM-DD]_[場所・テーマ]_[番号].jpg
例: 2026-07-15_fujisan-shinkansen_01.jpg
    2026-08-10_matsumoto-castle_03.jpg
    2026-06-20_kumano-nachi_goshuin_02.jpg
```

## 6. メディア別の写真仕様

| メディア | 推奨構図 | 解像度目安 |
|---------|---------|---------|
| Instagram フィード | 4:5 縦 or 1:1 正方形 | 1080×1350 |
| Instagram Stories | 9:16 縦 | 1080×1920 |
| Instagram Reels サムネイル | 9:16 縦 | 1080×1920 |
| Latte CH 動画背景 | 16:9 横 | 1920×1080 |
| note 見出し画像 | 16:9 横 | 1280×720 |
| X 添付 | 16:9 横 or 自由 | 1280×720以上 |

## 7. 写真資産の積み上げ目標

| 期間 | 目標 | 内容 |
|------|------|------|
| 月次 | 30枚以上撮影 | 神社・城・日常・新幹線含む |
| 3ヶ月 | 厳選100枚を資産化 | Instagram・note・Latte CH各メディアで使い切る |
| 年間 | 全国主要スポット写真を揃える | 熊野・伊勢・姫路・松本・京都 |

## 8. 写真から生まれるコンテンツの流れ

```
外出・撮影
    ↓
厳選・整理（使えるものだけ残す）
    ↓
┌────────────┬────────────────┬────────────┐
│ Instagram  │   Latte CH     │   note     │
│ 週1投稿   │ 動画背景・挿入  │ 記事画像   │
└────────────┴────────────────┴────────────┘
    ↓
X：告知・共感ツイート（写真添付）
    ↓
Kei Assist：実践者としての発信実績に蓄積
```
