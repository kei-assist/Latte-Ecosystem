## 1. このロードマップの目的

全国の移動・遠征・日帰り旅を Latte CH / SNS / note のコンテンツ資産へ変換する。

変換の基本ルール:

```
体験 → 気づき → 整える視点 → Latte CH / X / note
```

旅行チャンネル化しない。「その体験で何が整ったか」を軸にする。

## 4. 新幹線（新大阪→東京）車窓撮影ガイド

東海道新幹線（のぞみ）乗車時の撮影スポット。

**座席推奨: E席（D/E/F列の窓側・富士山側）**

| 区間 | 見どころ | 撮影タイミング | 難易度 |
|------|---------|-------------|-------|
| 京都〜米原 | **琵琶湖**（進行方向右側・D席） | 米原手前10分 | 低 |
| 米原〜岐阜羽島 | **伊吹山**（進行方向左側・E席） | 米原通過後すぐ | 低 |
| 名古屋〜浜松 | **浜名湖**（進行方向右側・D席） | 掛川〜浜松間 | 低 |
| 静岡〜三島 | **富士山**（進行方向右側・D席）⭐ | 新富士駅通過前後 | 高（天候依存） |
| 三島〜小田原 | **富士山〜箱根山系** | 三島通過後 | 中 |
| 小田原〜新横浜 | **小田原城**（進行方向右側） | 小田原駅通過直前 | 低 |

### 富士山撮影のコツ

```
最良条件: 晴れ・午前中（逆光になりにくい）
座席: 必ずE席（窓側・富士山側）を予約
速度: 270km/hで通過するため、シャッタースピードを上げる
     → スマホの場合はバースト撮影（連続撮影）で対応
タイミング: 新富士駅通過30秒前から構え始める
```

### 車窓撮影の基本

```
- ガラスへの映り込みを防ぐため、窓に顔・スマホを近づける
- シャッタースピード重視（ブレを防ぐ）
- 鉄道路線や電柱が入らないタイミングを待つ
- 日中は逆光に注意（朝の新大阪→東京方向が比較的撮りやすい）
```
