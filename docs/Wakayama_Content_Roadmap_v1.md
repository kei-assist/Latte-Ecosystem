## 1. このロードマップの目的

和歌山単身赴任の残り期間を、Latte CH / SNS / note のコンテンツ資産へ変換する。

「単身赴任」という情報は外に出さない。  
「和歌山に住んでいる期間に行ったこと・感じたこと・整えたこと」として発信する。

変換の基本ルール:

```
体験 → 気づき → 整える視点 → Latte CH / X / note
```

## 4. SNS展開案

### X（Twitter）

```
投稿タイプ1: 神社・御朱印の気づきをひとこと
例:「御朱印を集めていると、休日の『目的』ができる。それだけで気持ちが変わる。」

投稿タイプ2: 休日ルーティンの記録
例:「今日の朝：神社 → カフェ → ジム。それだけで十分に整った気がする。」

投稿タイプ3: Latte CH動画の告知
「新しい動画を出しました。御朱印を集め始めたら、休日が変わった話です。▶ [URL]」
```

### Instagram

- 御朱印帳の見開き写真（装飾なし・余白あり）
- 境内・鳥居の縦構図（縦型フィード向け）
- 神社の階段・石畳・自然光
- 那智の滝・熊野古道の景色（Reels向け15〜30秒）
- Latte BGMのサムネイルと世界観を合わせた自然系写真

## 6. 撮影チェックリスト（外出時）

### 神社・御朱印

- [ ] 鳥居（正面・奥行き構図）
- [ ] 参道・石畳・階段
- [ ] 本殿・拝殿（遠め・威圧感なし）
- [ ] 自然光の差し込む瞬間
- [ ] 御朱印帳（受け取り後・見開き）
- [ ] 御朱印の単体クローズアップ
- [ ] 境内の木・苔・静かな場所

### 自然・景色

- [ ] 縦構図（Instagram Stories / Reels向け）
- [ ] 横構図（YouTube サムネ / note見出し向け）
- [ ] 光の当たり方を意識した1枚
- [ ] 人が映らないタイミングを選ぶ

### 日常・ルーティン

- [ ] 朝のコーヒー・食事（手元のみ）
- [ ] ジムバッグ・準備風景（人物不要）
- [ ] 休日の本・読書風景

### 撮影しないもの（公開NG）

- 他者の顔が映る写真
- 職場・会社が特定できる場所
- 住所や生活拠点が特定できる風景
- プライベートな人間関係が分かる写真
