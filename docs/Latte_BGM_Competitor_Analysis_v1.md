## 分析の目的

| 目的 | 具体的な活用 |
|------|------------|
| タイトル・サムネイル研究 | CTRを上げるデザイン・文言を学ぶ |
| ジャンル空白地帯の発見 | 競合が手薄なニッチを制作候補にする |
| 再生数が伸びている要因把握 | 自チャンネルの優先戦略を更新する |
| プレイリスト設計の参考 | 回遊設計を改善する |

## 分析観点チェックリスト

競合動画を見るときに確認する項目:

### サムネイル

- [ ] 背景の色・トーン
- [ ] テキストの量・フォント・色
- [ ] ジャンルとデザインの一致度
- [ ] モバイル表示での視認性

### タイトル

- [ ] キーワードの順番（何を先に出しているか）
- [ ] 数字の使い方（1 Hour / 2 Hours / 8 Hours）
- [ ] 感情・シーン訴求の有無（Cozy / Peaceful / Deep など）
- [ ] チャンネル名の位置（冒頭 vs 末尾）

### 説明文

- [ ] 冒頭100文字で何を書いているか
- [ ] タイムスタンプの有無
- [ ] 他動画へのリンク設計
- [ ] プレイリストリンクの有無
- [ ] ハッシュタグの数・種類

### 動画本体

- [ ] 動画スタイル（静止画 / 波形 / 映像）
- [ ] 尺（1時間 / 2時間 / 長尺）
- [ ] 終了画面の設計

## 差別化ポジション整理

### Latte BGMが目指すポジション

```
大型チャンネル（Lofi Girl等）
    → ブランド・キャラクター・コミュニティで戦う → 差別化困難

中型量産型（Greenred等）
    → SEO×量産で戦う → Latte BGMが目指す現実的ゾーン

ニッチ特化型（Japanese Lofi等）
    → 特定テーマで圧倒的な本数 → 将来的な戦略オプション
```

**現在のLatte BGM戦略: 中型量産型を目指しながら、Japaneseテイストのニッチで差別化する**
