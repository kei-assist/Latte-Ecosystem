# SNS連携仕様

## プラットフォーム役割分担

| プラットフォーム | 役割 | コンテンツ方針 |
|--------------|------|--------------|
| YouTube (Latte BGM) | 英語圏向けBGM資産 | 長尺・継続投稿 |
| YouTube (Latte CH) | 日本語圏向け本編 | 週1本・信頼構築 |
| X (Twitter) | 共感・日常発信 | 短文・等身大の言葉 |
| Instagram | 世界観・ビジュアル | Latteキャラ・雰囲気 |
| TikTok | 短尺切り抜き | Latte CHの切り出し |
| note | 深堀り・文章資産 | 本編補完・思考整理 |

---

## 最終導線

```
Latte CH / Latte BGM（YouTube）
        ↓
X / Instagram / TikTok
        ↓
Kei Assist（副業・案件）
        ↓
スプレッドシート作成 / ダッシュボード / AI自動化案件
```

---

## X（Twitter）運用方針

- 等身大の言葉を優先
- Latte CH動画公開時に連動投稿
- 共感を呼ぶ短文（100字以内）
- 毎日投稿目標

投稿タイプ:
1. YouTube動画告知
2. お金・習慣・暮らしの気づき
3. 制作裏話・進捗報告
4. 共感系つぶやき

---

## Instagram運用方針

- Latteキャラを使った世界観訴求
- Reels: TikTok/Shorts流用
- フィード: Latte CH・BGMのビジュアル告知
- ストーリー: 制作進捗・日常

---

## TikTok運用方針

- Latte CH本編の切り出し（1〜3分）
- BGM紹介（Latte BGMのショート版）
- Shorts流用での二次展開

---

## note運用方針

- YouTube動画の補完記事
- お金・習慣・暮らしの深堀り記事
- ポートフォリオへの導線記事

---

## 投稿連携フロー

```
YouTube本編公開
    ↓ 同日
X告知ツイート（タイトル + URL + 一言）
    ↓ 翌日以降
Instagram告知（画像 + キャプション）
    ↓ Shorts/TikTok切り出し
TikTok / YouTube Shorts投稿
    ↓ 必要に応じて
note補完記事
```

---

## Kei Assistへの導線設計

SNS全体で「実践者」として見せる方針:

- 「AI活用学習中」ではなく「管理シート・業務改善ツールを実際に作っている人」
- Latte CH/BGMの制作・運営自体がポートフォリオ
- YouTube管理・自動化スクリプト・KPI管理をコンテンツ化

ポートフォリオ候補素材:
- Fitness Tracker（体重・筋トレ・習慣管理ダッシュボード）
- 売上日報シート
- BGM制作自動化スクリプト
- YouTube運営管理シート
