# Latte Ecosystem 全体設計

## ビジョン

> BGMで整えて、言葉で考える——それが Latte のスタイル。

Latteは「音で整う」と「言葉で整える」を両輪として、英語圏・日本語圏の双方にアプローチするコンテンツブランド。

## 各チャンネルの役割分担

### Latte BGM（音で整う）
- **ターゲット**: 英語圏
- **目的**: YouTube資産の積み上げ・将来的な収益化
- **運営**: 毎日投稿・Suno×Python自動化
- **導線**: BGM視聴者 → チャンネル登録 → 将来のブランド拡張

### Latte CH（言葉で整える）
- **ターゲット**: 日本語圏
- **目的**: 信頼構築・Kei Assist案件への導線
- **運営**: 週1本本編 + Shorts展開
- **導線**: 視聴者 → SNSフォロー → Kei Assist認知 → 案件

## ポートフォリオ方針

Latte Ecosystem自体が「実践者」としてのポートフォリオ。

見せ方の軸:
- 「YouTube運営を自動化した人」
- 「管理シートや業務改善ツールを実際に作っている人」
- 「AI活用で副業を実践している人」

「AI活用学習中」「日本製鉄勤務」「単身赴任中」は使わない。
