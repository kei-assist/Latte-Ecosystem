# Latte BGM SEO Keyword Library v1

> YouTubeタイトル・説明文・タグに使用するキーワード集。
> 検索流入を最大化するために選定。定期的に更新する。

---

## 活用方法

| 場所 | 推奨キーワード数 | 使い方 |
|------|--------------|-------|
| タイトル | 2〜3語 | メインKW + ジャンルKW + チャンネル名 |
| 説明文（冒頭100字） | 3〜5語 | 冒頭に自然に埋め込む（アルゴリズム重視） |
| タグ | 10〜15個 | 広義→狭義の順。完全一致・フレーズ一致を混在 |

## タイトルパターン別キーワード配置

### パターン1（シリーズ名前出し）

```
[Series Name] Vol.X | [Genre Keyword] | Latte BGM
例: Rainy Night Vol.3 | Sleep Music for Deep Rest | Latte BGM
```

### パターン2（用途前出し）

```
[Use Case] - [Series Name] Vol.X | Latte BGM
例: 1 Hour Sleep Music - Rainy Night Vol.3 | Latte BGM
```

### パターン3（感情・シーン前出し）

```
[Scene/Mood] BGM | [Series Name] | Latte BGM
例: Cozy Rainy Night BGM | Rainy Night Vol.3 | Latte BGM
```

**推奨: パターン1**（シリーズ認知を優先・回遊設計に有利）
