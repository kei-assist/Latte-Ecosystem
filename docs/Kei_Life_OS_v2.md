短期目標:

- 副業月5万円を作る
- 実績、制作物、発信を増やす
- 案件獲得や小さな収益化に近づく

中長期目標:

## 4. Latte Ecosystem OSの全体像

Latte Ecosystem OSのコンセプト:

```text
自分の生活と実践をAIで整えながら、音・キャラクター・文章・仕組みを資産化し、将来的にKei Assistへの信頼につなげる。
```

各領域の役割:

| 領域 | 役割 | 主な成果物 |
| --- | --- | --- |
| Latte BGM | 音で整える | 1時間BGM、サムネイル、プレイリスト、制作ログ |
| Latte CH | 日常を整える | ラテキャラ動画、習慣、休日、実体験コンテンツ |
| X | 日々の接点 | 公開告知、制作ログ、気づき、実践記録 |
| Instagram | 視覚的な接点 | サムネ、短尺、ラテ素材、写真 |
| note | 深掘り資産 | 制作記録、体験記、AI活用記事、運営ログ |
| GitHub | 運用本部 | 仕様書、テンプレート、ログ、改善履歴 |
| Codex | 実装と整理 | ドキュメント化、構成作成、ファイル整理、自動化 |
| Kei Assist | 仕事化の出口 | AI活用支援、発信支援、資料作成、動画制作支援 |

## 5. 啓一の基本姿勢

Codexは以下を前提にする。

- 学習者ではなく実践者として見せる
- 案件くださいではなく、積み上げを見せる
- 完璧なノウハウより、実際にやった記録を残す
- AIを使っていることを隠さない
- 本業を大切にしながら、副業資産を育てる
- 会社名、勤務先、具体的な職場情報は出さない
- 強すぎる自己啓発や煽りは避ける

発信のトーン:

- 落ち着いている
- 押しつけない
- 少し前向き
- 実体験ベース
- 生活感がある
- きれいごとにしすぎない
- 「整える」という軸に戻る

## 7. メディア別の運用ルール

### 7-1. Latte BGM

役割:

```text
整える音を届けるグローバル音楽チャンネル。
```

基本:

- 英語圏、とくに米国視聴者を主対象にする
- 1時間BGMを基本にする
- タイトル、説明文、タグは英語中心
- サムネイルは用途が1秒で分かる構造にする
- ブランド名は `Latte BGM` に統一する

優先カテゴリ:

1. Sleep / Rainy Night
2. Deep Focus / Study
3. Nature / Forest
4. Cafe / Reading
5. Relax / Meditation
6. Workout / Gym / Running

制作時の注意:

- 歌詞なしを基本にする
- 急な展開、強いサビ、派手なドロップは避ける
- カテゴリを色だけで識別しない
- 既存動画改善では、原則として音源を変更しない
- 音源、動画、画像本体はGit管理しない

### 7-2. Latte CH

役割:

```text
ラテと一緒に、少しずつ整える日本向けチャンネル。
```

基本:

- ラテキャラを必ず使う
- VOICEVOX 四国めたんを標準音声にする
- 落ち着いた世界観にする
- 静止画だけの動画にしない
- 軽いアニメーションを入れる
- すべてを「整える」という視点に戻す

Latte CHが扱うもの:

- 習慣
- 暮らし改善
- 軽い筋トレ
- 休日の過ごし方
- 神社巡り
- 御朱印
- エスコン遠征
- ファイターズ
- AI活用の裏側
- 制作ログ

Latte CHがやらないこと:

- 旅行チャンネル化
- 健康チャンネル化
- お金チャンネル化
- 野球解説チャンネル化
- 神社紹介専門チャンネル化
- AIノウハウ専門チャンネル化

## 9. 公開してはいけない情報

公開発信やGitHub上に出さない。

- 勤務先名
- 具体的な職場情報
- 住所や生活拠点の詳細
- 家族や他者の個人情報
- 会社の内部情報
- 副業規定に関わる誤解を招く表現
- 他者の顔が写る写真
- 未公開URLや限定公開URL
- 実収益の詳細
- 案件先や相談者の情報

避ける表現:

- 収益保証
- 医療効果保証
- 投資助言のように見える断定
- 過度な自己啓発
- 煽り

## 10. Codexへの作業委任ルール

Codexが進めてよいこと:

- 既存docsを読んだ上でのドキュメント作成
- 制作テンプレート作成
- Sunoプロンプト作成
- YouTubeタイトル、説明文、タグ作成
- SNS投稿案作成
- note構成案作成
- 制作ログテンプレート作成
- 既存方針に沿った整理

Codexが確認すべきこと:

- YouTube公開ボタンを押す作業
- 外部サービスのログインや権限変更
- 実収益や個人情報を含む内容の公開
- 大きな方針変更
- 旧仕様の削除
- ユーザーの未コミット変更を戻す作業

Codexが守ること:

- 作業前にREADMEと関連docsを読む
- git statusを確認する
- ユーザーが作った未コミット変更を勝手に戻さない
- 変更範囲を小さくする
- 新しい構想を勝手に足さない
- 必要なら新バージョンの文書として残す

## 11. 自動化の考え方

自動化の原則:

- いきなり完全自動化しない
- 人間の判断が必要な箇所を残す
- 作業をテンプレート化してから自動化する
- 成果が出た流れだけ仕組み化する
- 大容量メディアはGitHubに入れない
- 収益と信頼に近い作業を優先する

Latte BGM自動化の優先:

1. テーマキュー
2. Sunoプロンプトテンプレート
3. 投稿メタデータテンプレート
4. プレイリスト判定
5. SNS投稿文生成
6. 制作ログテンプレート
7. KPIレビュー
8. YouTube投稿補助

自動化しないもの:

- 音源の最終採用
- YouTubeの公開ボタン
- 権利確認
- 個人情報チェック
- 実収益の公開判断
