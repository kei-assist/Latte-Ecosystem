# KPI管理

## Latte BGM KPI

### 管理指標

| 指標 | 目標 | 確認頻度 |
|------|------|---------|
| 公開本数（累計） | 積み上げ継続 | 月次 |
| 総再生数 | 増加傾向 | 週次 |
| チャンネル登録者数 | 増加傾向 | 月次 |
| 平均視聴時間 | 改善傾向 | 月次 |
| インプレッションCTR | 改善傾向 | 月次 |

### 現在の状況（2026-06-06時点）

| 項目 | 状況 |
|------|------|
| 公開本数 | 15本+ |
| 最新公開 | Deep Focus Vol.4 |
| 次回制作候補 | Morning Piano Vol.3 |

### 改善優先度

1. 視聴維持率（長尺動画の完走率）
2. インプレッションCTR（サムネイル・タイトル）
3. チャンネル回遊率（プレイリスト経由視聴）
4. 英語タイトル・説明文の最適化
