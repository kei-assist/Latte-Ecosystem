## 1. このロードマップの目的

北海道日本ハムファイターズ / ESCONフィールド北海道への遠征・観戦体験を、Latte CH / X / noteのコンテンツ資産へ変換する。

**ファイターズコンテンツの軸:**

```
「好きなことで休日を整える」
```

野球解説チャンネルにしない。スポーツ観戦を「心と気持ちを整える行動」として発信する。

---

## 2. Latte CH方針との整合

| 項目 | 方針 |
|------|------|
| ✅ やること | 「推しを応援することで気持ちが整う話」として発信 |
| ✅ やること | エスコンの体験・雰囲気・感情をラテキャラで語る |
| ✅ やること | 遠征の準備・計画・終わったあとの気持ちをコンテンツ化 |
| ❌ やらないこと | 試合結果・戦力分析・選手評価 |
| ❌ やらないこと | 野球解説・ルール説明 |
| ❌ やらないこと | 応援強制・勝ち負けへの感情移入が強いコンテンツ |

## 3. Latte CH 動画企画（ファイターズテーマ）

| # | タイトル案 | 核となる気づき |
|---|----------|-------------|
| 1 | 好きなチームがあると、休日の設計が変わる話 | 目的のある外出が気持ちを整える |

| 3 | スタジアムで3時間、ちゃんと休んできた | 応援することで頭が空っぽになる |
| 4 | 推しがいると、暮らしのリズムが変わる話 | 「次の観戦」を楽しみに日常を整える |
| 5 | 遠征を終えた翌日に思うこと | 非日常→日常への着地の仕方 |

## 4. X（Twitter）展開案

### 試合観戦日の投稿パターン

```
【観戦当日・出発前】
「今日はスタジアムへ。遠征は準備の時点ですでに楽しい。」

【観戦中・ハーフタイム】
「スタジアムにいると、いつのまにか仕事のことを考えていない。
 これが観戦の価値だと思う。」

【観戦後・帰り道】
「[勝敗に関係なく] 今日もいい時間だった。
 また来る理由ができた。」
```

### 遠征計画ツイート

```
「次のエスコン遠征の計画を立てた。
 スケジュールを入れると、日常の組み立て方が変わる気がする。」
```

### ファイターズ×日常ツイート

```
「ファイターズの試合日程を確認するのが、週の楽しみのひとつになっている。
 好きなものがある生活は、ちょっとだけ余裕がある。」
```

## 6. 撮影チェックリスト（スタジアム・遠征）

### エスコンフィールド内

- [ ] 球場全景（外観・大きさが伝わる1枚）
- [ ] スコアボード・電光掲示板（試合情報なし・デザインとして）
- [ ] スタンド・座席の雰囲気（人物が映らないアングル）
- [ ] グッズ・応援グッズ（手元・購入品の静物）
- [ ] フード・スタジアムグルメ（手元・テーブル）
- [ ] 場内の光・夜景・雰囲気ショット

### 遠征途中

- [ ] 移動中の景色（新幹線の窓・空港等）
- [ ] 北海道の風景（遠征先の空気感）
- [ ] チームショップ・グッズ展示（人物なし）

### 撮影NGリスト

- 他の観客の顔が映る写真（必ず避ける）
- 選手・スタッフを至近距離で撮った写真
- スタジアムが著作権・撮影ルールで禁じている場所・場面

## 7. 遠征コンテンツ制作フロー

```
遠征計画を立てる
    ↓ X: 「遠征計画ツイート」
    ↓
遠征当日
    ↓ X: 当日ツイート（出発前・観戦後）
    ↓ 写真: スタジアム・グッズ・フード
    ↓
遠征翌日
    ↓ X: 感想・気づきツイート
    ↓
1週間以内
    ↓ note: 遠征記・体験記
    ↓
1ヶ月以内
    ↓ Latte CH: 「好きなことで休日を整える話」として動画化
    ↓
Instagram: 球場写真・グッズ写真を投稿
```
