> CTRを上げるサムネイル設計の基準書。
> 新規制作・リニューアル時に参照する。

| 項目 | 規格 |
|------|------|
| サイズ | 1280 × 720px |

## テキストルール

### メインテキスト（シリーズ名）

| 項目 | ルール |
|------|--------|
| 内容 | シリーズ名 + Vol.X のみ |
| フォント | 太め・視認性重視（Bold sans-serif） |
| サイズ | サムネイル幅の40〜50%を占める大きさ |
| 色 | 白 or クリーム（背景に応じて高コントラスト） |
| 位置 | 中央 or やや上寄り |

### サブテキスト

| 項目 | ルール |
|------|--------|
| 内容 | `1 Hour BGM` or `Sleep Music` などジャンル一言 |
| サイズ | メインテキストの30〜40% |
| 位置 | メインテキストの下 |

### チャンネル名テキスト

| 項目 | ルール |
|------|--------|
| 内容 | `Latte BGM` |
| 位置 | 右下 or 左下（固定） |
| 視認性 | 小さくてよい（補助的役割） |

## 背景デザインルール（ジャンル別）

| ジャンル | 推奨カラー・雰囲気 | 避けるもの |
|---------|----------------|---------|
| Sleep | 深い紺・黒・ダークパープル | 明るい色・白背景 |
| Focus / Study | ダークグリーン・濃紺・グレー | 赤系・派手な色 |
| Cafe / Lo-fi | 茶系・アンバー・温かみのあるグラデーション | 冷たい青系 |
| Nature | 森グリーン・アースカラー・霧がかった緑 | 人工物・都市感 |
| Meditation | 淡パープル・インディゴ・明るいグレー | 強いコントラスト |
| Morning | 淡いオレンジ・ゴールド・柔らかい白 | 暗い色・重い印象 |

## CTRを上げる要素

### 必ずやること

- [ ] テキストは最大3行まで（シリーズ名 / サブ / チャンネル名）
- [ ] モバイル表示（縮小時）でもシリーズ名が読める
- [ ] 背景とテキストのコントラスト比を確保（白文字なら暗背景）
- [ ] Vol.番号を明示（シリーズ回遊を促進）

### やってはいけないこと

- ✕ 顔写真・人物写真（BGMチャンネルの世界観と合わない）
- ✕ 文字を詰め込みすぎ（3要素を超えるテキスト）
- ✕ 明るすぎ・カラフルすぎ（睡眠・集中系BGMに不釣り合い）
- ✕ ジャンルと合わない背景（SleepなのにCafe画像など）
- ✕ Unsplash人物写真・著作権不明素材

## サムネイルA/Bテスト管理

| テスト番号 | 対象動画 | パターンA | パターンB | CTR(A) | CTR(B) | 採用 |
|---------|---------|---------|---------|--------|--------|------|
| T001 | | | | | | |

### テスト観点（優先順）

1. **テキスト有無**: 背景のみ vs テキストあり
2. **背景色トーン**: 暗め vs 明るめ
3. **Vol.番号位置**: 大きく中央 vs 小さく右下
4. **サブテキスト内容**: `1 Hour` vs `Sleep Music` vs `Relaxing`

## 既存サムネイル品質評価基準

| 評価 | 基準 |
|------|------|
| A（高CTR期待） | テキスト明確・背景ジャンル一致・モバイル可読 |
| B（改善余地あり） | 要素はあるが視認性やや低い |
| C（要リニューアル） | CTRが2%以下 or 背景・テキスト不一致 |
