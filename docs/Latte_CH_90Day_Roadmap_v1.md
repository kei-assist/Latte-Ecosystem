# Latte CH 90日ロードマップ v1

参照元: `Kei_Life_OS_v2.md`
作成日: 2026-06-06
対象期間: 2026-06-07 〜 2026-09-04（90日）

---

## 1. このロードマップの目的

90日間でLatte CHを「信頼構築メディア」として機能させる。
再生数を追わない。視聴者がLatte CHを「整える場所」として認識する状態を作る。

---

## 2. 90日間の数値目標

| 指標 | 現状 | 90日後の目標 |
|------|------|-----------|
| 公開EP数 | EP13まで | EP25〜30まで |
| 本編投稿ペース | 不定期 | 週1本（毎週木曜）安定 |

## 5. 制作スケジュール（週次）

| 曜日 | 作業内容 |
|-----|---------|
| 月 | 翌週分のスクリプト案を固める |
| 火 | スクリプト完成・VOICEVOX音声生成 |
| 水 | 動画編集（ラテアニメ・テキストフェード） |
| 木 | **YouTube公開日**・X告知ツイート |
| 金 | 翌日フォローツイート・Instagramサムネ投稿 |
| 土 | Shorts切り出し（月2本ペースで） |
| 日 | 週次レビュー・翌週テーマ決定 |

---

## 6. Latte CH 品質ゲート（公開前チェック）

- [ ] スクリプトにNGワードなし（稼げる/絶対/最強/勝つ/頑張れ）
- [ ] ラテキャラに動きあり（上下・左右・ズームのいずれか）
- [ ] 静止画のみの動画になっていない
- [ ] サムネイルにEP番号なし
- [ ] タイトルが「整える視点」になっている
- [ ] 冒頭30秒が共感・問いかけ型
- [ ] 旅行紹介・野球解説・お金ノウハウ専門になっていない

## 7. SNS連動フロー（本編公開時）

```
木曜 本編公開
    ↓

    ↓ 翌日（金）
フォローツイート（内容から引いた気づき1行）
    ↓ 翌々日〜
Instagram サムネイル or 写真をフィード投稿
    ↓ 1週間以内
Shorts切り出し（月2本ペースで消化）
    ↓ 必要に応じて
note補完記事（体験・思考整理系EP）
```
