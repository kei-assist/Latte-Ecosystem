# logs/

週次・月次レビュー記録を保存するディレクトリ。

## ファイル命名規則

```
[YYYY-MM]_monthly-review.md   # 月次レビュー
[YYYY-WXX]_weekly-review.md   # 週次レビュー（WXX = 週番号）
```
