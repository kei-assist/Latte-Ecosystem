# SNS 投稿ワークフロー

## YouTube 公開 → SNS 連動フロー

```
YouTube 本編公開
    ↓ 同日
X 告知ツイート
（タイトル + URL + 一言コメント）
    ↓ 翌日以降
Instagram 告知
（画像 + キャプション）
    ↓ 数日以内
Shorts / TikTok 切り出し投稿
    ↓ 必要に応じて
note 補完記事
```

---

## X（Twitter）投稿ルール

### 告知ツイート形式

```
[タイトル]

[一言コメント（共感・問いかけ）]

▶ [YouTube URL]

#[タグ1] #[タグ2]
```

### 独立ツイート形式

- 100字以内
- お金・習慣・暮らしの気づき
- 「〜な人いませんか」「〜ってよくある」型

### 禁止表現

NGワード（稼げる/絶対/最強/勝つ/頑張れ）は SNS でも使用禁止

---

## Instagram 投稿ルール

### フィード投稿

- Latteキャラ入り画像を使用
- キャプション: 動画の要点を3行以内で
- ハッシュタグ: 15〜20個

### Reels

- TikTok / YouTube Shorts 流用可
- キャプションは短く（2〜3行）

---

## TikTok 投稿ルール

- Latte CH 本編切り出し（1〜3分）
- BGM紹介（Latte BGMのショート版）
- キャプションは短く・ハッシュタグ5〜10個

---

## note 記事ルール

- YouTube動画の補完・深堀り
- タイトルは動画と関連性を持たせる
- 末尾にYouTubeへの誘導リンク

---
