# Latte CH エピソードスクリプトテンプレート

## ファイル命名規則

```
scripts/ep[番号]_[テーマキーワード].md
例: scripts/ep14_jouhou_atsumeru.md
```

---

## スクリプト構成テンプレート

```markdown
# EP[番号]: [タイトル]

**テーマ**: [お金 / 習慣 / 暮らし]
**想定尺**: [5〜8分]
**Shorts候補**: [あり / なし]

---

## 冒頭（0〜30秒）

[共感・問いかけから入る]
例: 「〜っていう経験、ありませんか？」

---

## 本編

### ポイント1（30秒〜2分）

[見出し]

[本文 150〜200字]
[具体例・たとえ話]

---

### ポイント2（2〜4分）

[見出し]

[本文 150〜200字]
[具体例・たとえ話]

---

### ポイント3（4〜6分）

[見出し]

[本文 150〜200字]
[具体例・たとえ話]

---

## 締め（6〜7分）

[押し付けない締め方]
例: 「もし気になったら、まず一つだけ試してみてください。」

---

## NGワード確認

- [ ] 稼げる → 使っていない
- [ ] 絶対 → 使っていない
- [ ] 最強 → 使っていない
- [ ] 勝つ → 使っていない
- [ ] 頑張れ → 使っていない

## サムネイルメモ

[サムネイルに入れるテキスト案]
```

---

## スクリプト作成チェックリスト

- [ ] 冒頭が共感ベース（問いかけ型）
- [ ] ポイントが3〜4つ
- [ ] 具体例・たとえ話あり
- [ ] NGワード使用なし
- [ ] 締めが押し付けでない
- [ ] Shorts候補箇所に目印あり
