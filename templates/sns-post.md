```
新着BGM🎵

[タイトル] — [ジャンル]

[一言コメント]

▶ [YouTube URL]

#LatteBGM #[ジャンル]Music #作業用BGM
```

### Latte CH 公開告知

```

[タイトル]

[共感フレーズ or 問いかけ（30〜50字）]

```

### 独立ツイート（共感系）

```
[気づき・あるある（50〜100字）]

[一言締め]
```

例:
```
情報を集めるほど動けなくなる。
「もう少し調べたら」が増えるほど、最初の一歩が遠くなる気がする。
```
