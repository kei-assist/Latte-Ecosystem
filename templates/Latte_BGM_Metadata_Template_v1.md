# Latte BGM Metadata Template v1

> YouTube投稿時のタイトル・説明文・タグをジャンル別にまとめたテンプレート集。
> [ ] 内を埋めてそのまま貼り付けて使う。

---

## 使い方

1. 投稿するジャンルのブロックをコピー
2. `[Series Name]` `[Vol.X]` `[URL]` `[関連シリーズURL]` を埋める
3. YouTubeの該当欄に貼り付け
