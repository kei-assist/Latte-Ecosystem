# Latte BGM Suno Prompt Library v1

> 再利用可能なSunoプロンプト集。ジャンル別に整理。
> 使用後は「使用日・採用結果」を末尾に記録する。

---

## プロンプト構成ルール

```
[Style Tags]  ジャンル・楽器・テンポ・雰囲気
[Lyrics]      instrumental（歌詞なし固定）
[Mood]        感情・シーン
[Structure]   ループ性・展開の有無
```
