# Latte BGM KPI管理

## 管理指標

| 指標 | 目標 | 確認頻度 |
|------|------|---------|
| 公開本数 | 累計積み上げ | 月次 |
| 総再生数 | 増加傾向 | 週次 |
| チャンネル登録者数 | 増加傾向 | 月次 |
| 平均視聴時間 | 改善 | 月次 |
| インプレッションCTR | 改善 | 月次 |

## 改善優先度

1. 視聴維持率（長尺動画の完走率）
2. インプレッションCTR（サムネイル・タイトル）
3. チャンネル回遊率（プレイリスト経由視聴）
4. 英語タイトル・説明文の最適化

## KPIレビュー運用

- 週次: 再生数・視聴時間の確認
- 月次: 登録者・CTRの確認と改善方針策定
- 四半期: ジャンル戦略・シリーズ優先度の見直し
